# deepdive-2
Tygo, Bram, Pascal, Milano

## Inleiding / Projectomschrijving
- het doel voor het project is om een nieuw ontwerp te maken en een prototype uit te brengen.
- de opdracht gever is Martin.
- een mooie vernieuwde website met een minigame er in.
- doelgroep is jongvolwassenen/volwassenen.
- een aantrekkelijk en interactief ook moet het amuseerent zijn ervaring op de website die je aan trekt om naar de verkoopplaats te komen.

## Must-haves
op de website moet minimaal:
- minimalistische interacties 
- minigame
- over ons
- amuserent uiterlijk

## Nice-to-haves / toekomstige uitbreidingen
- sfeer verduidelijken
- code / website / project op schonen

## Functionele eisen
- informatie over het bedrijf kunnen vinden
- plaats/ tijd van de boom verkoop kunnen vinden
- een game kunnen spelen 

## Technische eisen
het gebruik van:
- Tailwind.css
- JavaScript
- LocalStorage
- C#
